# Kinektro---IHC
Kinektro es un simulador de DJ en realidad virtual que combina mandos VR y captura corporal con Kinect de XBOX One para controlar una mesa de mezclas en 3D. Permite seleccionar canciones, cargarlas en vinilos, ecualizarlas y aplicar efectos con el movimiento del cuerpo sin equipos físicos costosos.
